Thumbico
========

Thumbico shows the thumbnail or icon that Windows itself produces for any
file, folder, or drive, at any size you ask for, pixel for pixel. You can
save the image to a file or copy it to the clipboard.


Running Thumbico
----------------

Thumbico is in your Start menu. If you asked for a desktop shortcut while
installing, it is there too.


Settings
--------

Thumbico keeps its settings in Thumbico.settings.json, under your Windows
user profile:

    %LocalAppData%\Aurelitec\Thumbico

If Thumbico was installed for all users, each Windows user still has
their own settings file, in their own profile.

Uninstalling leaves that file alone, so your options are still there if
you install Thumbico again. Delete the folder by hand if you want them
gone.


Uninstalling
------------

Open Settings, go to Apps, find Thumbico in the list, and choose
Uninstall.


System requirements
-------------------

Windows 10 or Windows 11, 64-bit.
