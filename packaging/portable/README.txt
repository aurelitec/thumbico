Thumbico - Portable edition
===========================

Thumbico shows the thumbnail or icon that Windows itself produces for any
file, folder, or drive, at any size you ask for, pixel for pixel. You can
save the image to a file or copy it to the clipboard.


Running Thumbico
----------------

No installation is needed. Extract all the files into a folder of your
choice, then run thumbico.exe. Keep the files together: the program needs
every file and the data folder beside it.


Settings
--------

This copy keeps its settings in Thumbico.settings.json, beside
thumbico.exe, so they travel with the folder. Put the folder where you can
write to, such as a USB drive or your Documents folder.

Do not delete Thumbico.settings.json: without it, Thumbico keeps its
settings in your Windows user profile instead.


System requirements
-------------------

Windows 10 or Windows 11, 64-bit.
